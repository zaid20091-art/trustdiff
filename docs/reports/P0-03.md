# تقرير P0-03 — تقوية عزل تنفيذ الاختبارات

**الحالة:** مُنجز في جانب المضيف ومُختبر بدوكر **محاكى**؛ اختبارات Docker الحقيقية مكتوبة لكنها **تُتخطى هنا** وتعمل في job `docker-integration`. وضع MicroVM يعتمد على بيئات تشغيل خارجية (gVisor/Kata) ولم يُجرَّب فعلياً.

## 1. السبب الجذري (ما ثبت بالتشغيل وما بقي فرضية)
| المشكلة | الحالة |
|---|---|
| `capture_output` يحتجز كامل مخرجات الأمر في ذاكرة المحقق قبل الاقتطاع | **مثبت:** 400 MB كاملة في الذاكرة |
| `.git` و`.trustdiff` (ledger/أدلة) وأي `.env` غير متتبَّع مقروءة داخل الحاوية (ربط جذر المستودع كاملاً) | ثابت من الشيفرة |
| عند المهلة يُقتل عميل `docker` فقط؛ الحاوية قد تستمر | **فرضية** من الشيفرة (`subprocess.run(timeout)` بلا `--name`)؛ تحتاج Docker حقيقياً، والاختبار الحقيقي مكتوب |
| لا هوية/اسم مؤقت لكل مهمة، لا حد للقرص/الملفات، `--pull` غير مقيَّد | ثابت من الشيفرة |
| `git archive` يحترم `export-ignore` فيستطيع المرشّح إخفاء اختباراته من اللقطة | ثابت من سلوك Git (عالجته بدل أن أقع فيه) |
| مسار challenge قابل للاستبدال بعد توليده (داخل المستودع) | ثابت من الشيفرة |
| FIFO غير متتبّع يعلّق `worktree_digest` | **فرضية مُنفاة:** Git لا يسرد الملفات الخاصة؛ أبقيتُ القراءة المحمية كدفاع إضافي |

## 2. التعديل (`trustdiff_runner.py`, `trustdiff_safe.py`)
* **لقطة نظيفة للـ commit** عبر فهرس خاص + `checkout-index` (بلا `.git`/`.trustdiff`/غير المتتبَّع، ولا يحترم `export-ignore`)، حدود 100 ألف ملف / 512 MB، تُحذف في `finally`.
* **هوية مؤقتة لكل مهمة:** `--name=trustdiff-<uuid>` + label؛ مسار challenge يُنسخ لنسخة خاصة قبل التركيب (ويُرفض إن لم يكن ملفاً عادياً).
* **تنظيف مضمون:** عند المهلة أو تجاوز المخرجات: `docker kill <name>` ثم `rm -f` ثم مسح بالـ label ثم تحقق؛ وإن بقيت حاوية يُطبع تحذير صريح.
* **مخرجات محدودة:** `bounded_run` يقتل مجموعة العمليات (بما فيها الأحفاد) عند المهلة، ويحتفظ بآخر 1 MiB فقط ويقتل الأمر فوق 64 MiB.
* **حدود الموارد:** `--pids-limit`, `--memory`, `--cpus`, `--ulimit nofile/fsize/core`, `--ipc=none`, tmpfs 64 MiB بلا exec، `--stop-timeout`.
* **حظر التوسعة بالبناء:** `build_argv` يرفض `--privileged`, `-v`, `--device`, `--cap-add`, `--network=host`, `--pid=host`, … وأي مصدر تركيب هو socket/FIFO/جهاز/symlink/اسمه `docker.sock`/جذر المضيف.
* **ثبات الصور:** `--pull=never` + `check --require-pinned-image` (يرفض صورة بلا `@sha256`). الاعتماديات تأتي من الصورة المثبتة لأن الشبكة معطلة.
* **وضع عزل أقوى (`--runtime`)**: `runsc` (gVisor) أو Kata (microVM) بنفس القيود؛ قائمة سماح، فحص مسبق أن الـ daemon يسجّل البيئة، وفشل مغلق بدل الرجوع إلى `runc`. يُسجَّل `runtime`/`isolation` في الأدلة.
* `run()` للتنفيذ المضيف (غير موصى به) صار محدوداً زمناً وذاكرة أيضاً.

## 3. الاختبارات (`tests/test_runner_hardening.py`, 32 اختباراً)
* **بدوكر محاكى (تعمل هنا):** محتوى اللقطة بالضبط، commit لا HEAD، `export-ignore`، قبول/رفض مصادر التركيب (socket/FIFO/symlink/فاصلة/`docker.sock`)، أعلام argv الإلزامية والممنوعة، قتل الحاوية بالاسم عند المهلة، فيضان المخرجات، حذف مساحة العمل بعد الفشل، الإبلاغ عن حاوية متبقية، هوية فريدة لكل مهمة، التحقق من المدخلات، بيئات التشغيل المسموحة/المفقودة.
* **Docker حقيقي (مكتوبة، تُتخطى هنا):** الشبكة معطلة، مساحة العمل للقراءة فقط ونظيفة، لا docker.sock، مستخدم 65534 بلا capabilities، لا تسرّب لمتغيرات المضيف، المهلة تزيل الحاوية فعلاً، fork-bomb محصور بـ pids-limit، وتشغيل تحت `TRUSTDIFF_TEST_RUNTIME`.
* طفرات: إزالة `--cap-drop`، `--network=none`، قتل الحاوية، فحص docker.sock، استخدام HEAD بدل commit، منع الفيضان ⇒ كلها قُتلت (بعد تقوية اختبارين كانا يتركان طفرتين تعيشان).

## 4. أثر التوافق
* الاختبارات تعمل على **commit الهدف** لا شجرة العمل: الملفات غير المتتبَّعة لم تعد مرئية. (`check` يشترط شجرة نظيفة أصلاً، فلا أثر على نتائج PASS.)
* `run_docker(..., commit=None, runtime=None)` توقيعان اختياريان؛ المستدعون القدامى يعملون (`commit=None` ⇒ `HEAD`).

## 5. القيود المتبقية
* Docker ليس VM. وضع MicroVM يتطلب تثبيت Kata/gVisor وتسجيله في الـ daemon؛ لم يُجرَّب هنا. لا يوجد backend Firecracker مباشر.
* «هوية مؤقتة» = اسم/label/مساحة عمل/مستخدم غير مميز لكل مهمة، لا بيانات اعتماد سحابية مؤقتة (لا توجد أصلاً أسرار داخل الحاوية).
* حد القرص: tmpfs و`ulimit fsize` فقط؛ لا حصة قرص على مستوى الـ daemon.
* اختبار تكامل Docker الحقيقي لم يُنفَّذ في بيئة التسليم.
