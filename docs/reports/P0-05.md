## 2. التعديل
* `trustdiff_safe.py` مشترك: `bounded_run`, `run_git` (يعطّل fsmonitor/hooks/pager/system config ويُنظّف البيئة)، **`git_config_risks`** (يرفض الإعدادات القادرة على التنفيذ)، `regular_file_sha256` (لا يتبع رابطاً ولا يقرأ خاصاً/ضخماً)، `read_regular_text`, `clean_repo_path`, `parse_name_status_z`, **`regex_hits`** (regex غير موثوق في عملية معزولة بمهلة 5 ثوانٍ؛ المهلة = ERROR).
* مسارات `-z` في كل مكان؛ diff لكل مسار حرفي (`:(literal)`) بدل تحليل الرؤوس؛ `--no-ext-diff --no-textconv`.
* `validate_contracts`: مخطط صارم (حدود طول/عدد، `timeout_seconds` 1–600 عدد صحيح، `command` ≤ 64 نصاً، معرفات فريدة بلا محارف تحكم، منطقيات حقيقية)، وحد 1 MB للسياسة والادعاءات.
* diff أكبر من 16 MiB أو تعذّر قراءته ⇒ `ERROR` (لا نجاح صامت).
* ماسح JS بلا تراجع تربيعي؛ `ast` يتحمل التداخل/NUL/الذاكرة ويُحصي الملف «متخطى»، وأي ملف تحليل ناقص يرفع `incomplete` وفجوة `analysis_incomplete`.
* تقارير: ترميز دفاعي لأنواع غير متوقعة، ترميز HTML، تحييد `@mentions`، حد 20 MiB، ومعالج أخطاء عام للـ CLI (`ERROR: …` رمز 2 بدل Traceback).
* حقل جديد في التقرير `unusual_paths` (مسارات بأسطر جديدة/محارف تحكم) و`git_config_audit`.

## 3. الاختبارات (`tests/test_input_hardening.py`, 30 اختباراً)
* **انحدارات** لكل بند أعلاه (بما فيها ملفات بأسماء Unicode/مسافة+`b/`/علامة اقتباس/tab/سطر جديد/يابانية، ورابط رمزي متتبَّع إلى `/etc/hostname` لا يُقرأ).
* **Fuzzing بذور ثابتة:** 4000 عقد عشوائي (خاصية: لا يُرفع إلا `ValueError` والمقبول يحقق المخطط)، 2000 مدخل لمنظّفات النص (حدود)، 3000 بايت عشوائي لمحلل المسارات، 300 نص عدائي لماسح JS (زمن)، 60 regex عشوائي، و120 تقرير عشوائي للمدقق (**لا استثناء ولا VERIFIED ولا PASS أبداً**).
* **خصائص:** كل طفرة ورقة على حزمة موقّعة تُرفض؛ حزم وهمية عشوائية لا تُقبل؛ أرتال Hypothesis اختيارية (تعمل إن ثُبّتت).
* **حدود الحجم/الزمن/الذاكرة:** ملف مصدر 1MB+، تقرير 5MB+، سياسة متداخلة 200 ألف مستوى، مخرجات 400MB (RSS < 200MB)، diff 20MB.
طفرات: إعادة ReDoS، إزالة التقاط RecursionError، رؤوس diff، إزالة `-z`، إزالة فحص git config، إزالة مخطط العقود، إلغاء مهلة regex، عودة خلل unhashable ⇒ كلها قُتلت.

## 4. أثر التوافق
* عقود صالحة تعمل كما هي؛ عقود بحقول غير صالحة ترفض برسالة تسمّي الحقل (كانت تنهار أو تُقبل بصمت).
* `worktree_sha256` يُحسب بتجزئات الملفات (القيمة تتغير؛ لم تكن واجهة ثابتة).
* مستودعات بإعدادات git تنفيذية تُرفض ما لم يُفعَّل `TRUSTDIFF_TRUST_GIT_CONFIG=1` (يُسجَّل في التقرير).

## 5. القيود
* `ast.parse` على بيئات Python قديمة جداً قد ينهار على مستوى المفسّر بدل استثناء (3.10+ يرفع استثناءات؛ لم أجرّب 3.10/3.11 هنا).
* لا fuzzing متواصل (coverage-guided)؛ البذور ثابتة ومحدودة التكرار.
* حدود الحجم/الزمن مضبوطة بتقدير معقول وليست مُعايَرة على مستودعات ضخمة.
